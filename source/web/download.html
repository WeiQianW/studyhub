Install · 安装
  1. Unzip the download, and keep MechatronicsStudyHub.exe and WebView2Loader.dll together.解压后，请把这两个文件放在同一个文件夹里。
  2. Double-click MechatronicsStudyHub.exe.双击运行。
  3. If Windows says “Windows protected your PC”, choose More info → Run anyway (the app is not code-signed).若出现“Windows 已保护你的电脑”，请点“更多信息 → 仍要运行”（应用未做代码签名）。
Updates · 更新

Notes and features update by themselves whenever the computer is online (at start-up and every 15 minutes). Each downloaded file is checked against its SHA-256 fingerprint before it is used. If a new version of the app itself comes out, the app shows a “Download” notice.联网时（启动时及每 15 分钟）笔记和功能会自动更新，每个下载的文件都会先校验 SHA-256 指纹。若应用本身有新版本，应用内会显示“下载”提示。
